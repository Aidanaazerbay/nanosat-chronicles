# Nanosat Chronicles (UniSat Project)

**Nanosat Chronicles** is an interactive engineering simulator developed by team **UNIHack** as part of the UniSat initiative (supported by UNICEF and KBTU). 

The game combines hands-on engineering, problem-solving, and gamified learning to teach users how to design and configure custom nanosatellites for unique extraterrestrial clients.

## 🎯 Project Goals & Challenges Addressed
1. **Hands-on Experience:** Bridging the gap by providing practical simulation mechanics.
2. **Engagement & Motivation:** Overcoming lack of project ideas and motivation through a gamified workflow.
3. **Immersive Learning:** Deep dive into the process of spacecraft assembly and client collaboration.

## Technical Specifications & Gameplay
* **Engine & Language:** Built on **Unity** using **C#**.
* **Platforms:** Available for desktop PCs (**Windows, macOS, Linux**).
* **Perspective:** First-person view inside an interactive laboratory workspace.
* **In-Game Economy & Mechanics:** Features client orders inspired by management games (like *Boba Tale* and *Good Pizza, Great Pizza*), point systems, and progress tracking.
